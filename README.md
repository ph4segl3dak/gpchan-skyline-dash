# 지피짱: 스카이라인 대시 (SKYLINE DASH!)

「네온 아르카나」를 갈아엎은 새 게임. 기존 GPChan v026a VRM으로 노을 진 옥상을 끝없이 달리는 **3차선 파쿠르 러너**다. 점프·슬라이드·차선 이동으로 장애물을 피하고, 빌딩 사이를 뛰어넘고, 긴 틈은 옆 빌딩 **벽을 타고** 건넌다. 기술을 이어 배율을 ×8까지 올리는 점수 경쟁이 핵심이다.

## 실행

```sh
cd "/Users/seunghuncha/Documents/New project/sites/gpchan_runner"
python3 serve.py 4188
```

[스카이라인 대시 열기](http://127.0.0.1:4188/)

`serve.py`는 캐시를 끈 로컬 서버다(수정 후 새로고침하면 바로 반영). Three.js·VRM·후처리·효과음/음악 합성이 모두 로컬에 있고 npm 설치·CDN·외부 서비스가 필요 없다. `file://`로는 열리지 않는다.

## 조작

| 입력 | 동작 |
| --- | --- |
| ↑ / W / Space | 점프. 공중에서 한 번 더 누르면 공중제비 2단 점프 |
| ↓ / S | 슬라이드. 공중에서는 급강하 후 착지 슬라이드 |
| ← → / A D | 차선 이동. 긴 틈 위 공중에서 벽 쪽으로 누르면 벽타기 |
| Esc / P | 일시정지 |
| M | 소리 끄기/켜기 |
| 터치 | 스와이프 ↑↓←→, 짧은 탭 = 점프 |

조작감 보정: 코요테 타임 0.11초(가장자리에서 늦게 눌러도 점프), 점프 버퍼 0.16초(착지 직전 입력 예약), 착지 직전 공중 입력은 2단 점프를 소모하지 않음, 살짝 모자란 높이(1.15 m 이내)는 자동으로 **기어오르기**, 옆에서 부딪히면 즉사 대신 튕겨 나오며 배율만 감소.

## 게임 규칙

- 속도는 거리에 따라 14 → 최대 29 m/s로 부드럽게 오른다.
- 장애물: 낮은 바리케이드(점프), 머리 높이 간판(슬라이드), 화물 컨테이너(차선 변경 또는 점프해서 위로, 일부는 경사로), 떠 있는 드론(피하거나 뛰어넘기), 좌우로 움직이는 드론.
- 빌딩 사이 틈: 일반 틈(점프·2단 점프), 긴 틈(옆 빌딩 벽타기 또는 점프대). 높이 차이가 있고, 착지 직후에는 장애물 없는 구간을 둔다.
- 기술과 배율: 퍼펙트 점프(가장자리 끝에서 도약), 퍼펙트 허들, 슬라이딩, 아슬아슬 회피, 벽타기, 공중제비, 점프대, 기어오르기, 부수기. 기술이 FLOW 게이지를 채우면 배율 +1(최대 ×8), 가만히 있으면 서서히 줄고 옆 충돌 시 −2.
- 아이템: 오버드라이브(4.5초 무적 질주, 장애물 부수기, 틈 위 활공), 자석(9초 칩 흡수), 실드(충돌·추락 1회 방어).
- 미션: 항상 3개. 달성할 때마다 ★ 1개와 영구 점수 보너스 +5%, 같은 종류는 다음 단계로 어려워진다.
- 시간대: 거리에 따라 노을 → 네온 밤 → 새벽으로 하늘·조명·창문 불빛이 바뀌며 반복된다.
- 첫 두 판(또는 최고 기록 1,500점 미만)은 점프·슬라이드·차선·틈·드론·벽타기·급강하를 순서대로 알려주는 튜토리얼 코스로 시작한다.
- 최고 기록·미션·소리 설정은 브라우저 localStorage에만 저장한다. 탭을 숨기거나 창 포커스를 잃으면 자동 정지한다.

## 파일

- `src/sim.js`: 렌더링과 분리한 순수 규칙. 시드 기반 코스 생성, 이동·충돌·착지, 기술·배율·점수.
- `src/autopilot.js`: 공정성 시험과 `?auto=1` QA용 자동 플레이어. 플레이어와 같은 입력만 보낸다.
- `src/character.js`: 원본 VRM의 절차적 파쿠르 애니메이션(달리기, 점프/낙하, 공중제비, 슬라이드, 벽타기, 기어오르기, 충돌, 타이틀 손 흔들기, 콤보 때 뒤돌아 윙크).
- `src/world.js`: 하늘 셰이더·구름·시간대 팔레트, 옥상/옆 빌딩/원경, 장애물·벽·점프대·칩, 입자·속도선.
- `src/audio.js`: WebAudio로 합성한 152 BPM 음악(배율이 오를수록 아르페지오·멜로디 추가)과 효과음.
- `src/missions.js`: 미션 풀과 진행.
- `src/main.js`: 렌더러·블룸 후처리, 입력, 카메라, HUD, 화면 전환, 저장.
- `assets/jibbi_chan_bunny_vroid_v026a_stocking_neutral.vrm`: 기존 GPChan v026a 원본의 변경 없는 복사.
- `vendor/`: Three.js 0.169.0(후처리 패스 포함), three-vrm 3.3.1. 각 MIT LICENSE.

이전 게임 `sites/gpchan_arcana/`(네온 아르카나)와 `sites/gpchan_rooftop/`(야근 탈출)은 지우지 않고 보존했다.
